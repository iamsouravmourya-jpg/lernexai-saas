LERNEXAI ONE-SHOT COURSE PUBLISH FORMAT
======================================

Use this format when generating a new course with AI so the whole course can be published in one run with minimal follow-up.

GOAL
----
Produce one complete, self-contained course package that can be pasted into Supabase SQL Editor and run once.
The package should create:
- the course row
- all modules
- all lessons
- all lesson quizzes
- all module quizzes
- the final exam question set

BEST PRACTICE
-------------
1. Use JSON as the AI authoring format.
2. Use SQL as the final execution format in Supabase.
3. Keep quiz questions aligned to the exact lesson/module content.
4. Use zero-based indexing for correct answers.
5. Keep the structure consistent so no extra clarification is needed.

LESSON QUIZ RULES
-----------------
- Lesson quiz questions must come only from the lesson just taught.
- If a lesson has no quiz, keep "quiz": null or omit it.
- Do not reuse future lesson content in earlier lesson quizzes.
- Keep lesson quizzes short: 1 to 3 questions is ideal.

MODULE QUIZ RULES
-----------------
- Module quiz questions must cover the full module, not only one lesson.
- Put module quizzes under the module object as "module_quiz".
- A module quiz can appear after the last lesson is completed.
- Keep module quiz time limits higher than lesson quiz time limits.

FINAL EXAM RULES
----------------
- Final exam should cover the whole course.
- Keep final exam questions distributed across all modules.
- Use the same question object format.
- Keep correct answers hidden from the browser; only store them in the backend/SQL.

SUPABASE SQL MAPPING
--------------------
Use the following tables and columns when converting the JSON to SQL:

courses
- title
- description
- category
- difficulty
- is_premium
- total_modules
- estimated_hours
- cover_image_url

modules
- course_id
- module_number
- title
- description
- order_index

lessons
- module_id
- lesson_number
- title
- content
- content_type
- video_url
- duration_minutes
- order_index

quizzes
- course_id
- module_index
- lesson_id (nullable, for lesson quizzes)
- questions (jsonb)
- passing_score
- time_limit_minutes

final_exam_questions
- course_id
- module_index
- difficulty
- question
- options (jsonb)
- correct_answer
- explanation
- order_index

SQL PUBLISH PATTERN
-------------------
When publishing a new course, use one transaction:

BEGIN;
1. Insert or replace the course row.
2. Insert all modules.
3. Insert all lessons.
4. Insert lesson quizzes with lesson_id when needed.
5. Insert module quizzes with lesson_id = NULL.
6. Insert final exam questions.
COMMIT;

IDEMPOTENT RUN PATTERN
----------------------
If you want safe re-runs, use a cleanup step before insert:
- delete child rows first
- then delete the course row
- then insert everything again

Example order:
1. DELETE final_exam_questions for course
2. DELETE quizzes for course
3. DELETE lessons for modules in course
4. DELETE modules for course
5. DELETE course row
6. INSERT fresh course data

QUESTION QUALITY CHECKLIST
--------------------------
Before running SQL, verify:
- every lesson has content that matches its quiz
- module quiz questions reflect all lessons in that module
- option arrays are always in the same order
- correct_answer is a zero-based index
- explanations are short and clear
- module_number and lesson_number are sequential
- no duplicate quiz content across different lessons unless intentional

AI PROMPT TEMPLATE
------------------
Use this prompt when generating a course with AI:

"Generate one complete course in the exact JSON structure below. Return only valid JSON, no markdown, no comments, no extra text. The course must include course metadata, modules, lessons, lesson quizzes, module quizzes, and final exam questions. Keep quizzes aligned to the lesson content. Use zero-based correct_answer indexes. Make the course beginner-friendly and ready to publish in Supabase in one run."

PUBLISHER NOTES
---------------
- If the course is beginner friendly, keep the level as "Beginner".
- If the course is for mixed users, use "Beginner to Intermediate".
- Use one clear theme and do not mix unrelated topics.
- Keep the course flow simple: lesson -> checkpoint quiz -> next lesson -> module quiz -> final exam.
- If adding a second course, make sure the title is unique and the course category is visible in Browse.
