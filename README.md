# 🚀 LernexAI — Personalized AI Learning Platform

An ongoing, live educational SaaS MVP built in public. LernexAI leverages advanced generative AI models and serverless backends to engineer personalized, dynamic learning paths and bilingual micro-tutoring experiences in real-time.

🌐 **Live Demo:** [lernexai.site](https://lernexai.site)  
⚙️ **Status:** Under Active Development (*Building in Public*)

---

## 🛠️ Tech Stack & System Architecture

This project is built using a modern, serverless architecture optimized for high performance and zero-cold starts:

- **Frontend & UI/UX:** HTML5, CSS3, Tailwind CSS (Engineered using component-driven rapid prototyping via `v0`)
- **Core Engine & Logic:** JavaScript (ES6+), Python 3
- **AI Orchestration:** Gemini API (Context-aware prompt routing for curriculum structure and quiz mapping)
- **Backend & Database:** Supabase (BaaS) with PostgreSQL for real-time authentication and secure session tracking
- **CI/CD & DevOps:** GitHub Actions (Automated workflow) with Push-to-Deploy hosting on Vercel

---

## 🔥 Key Features (Under Active Iteration)

- **AI Course Architect:** Generates customized roadmap JSONs instantly based on specific user learning targets.
- **Bilingual AI Tutor:** Conversational concept breakdown switching dynamically between English and Hindi.
- **Automated Certification Pipeline:** Programmatic tracking of user quiz milestones resulting in verified graded certificates (O to D scale).
